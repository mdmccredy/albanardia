# Albanardia

Max McCredy's fictional US state, the Windward State, and its capital Silverbrooks (SB).

**Live site:** https://mdmccredy.github.io/albanardia/

| Folder | What's in it |
|---|---|
| `map/` | Interactive map: `index.html`, `style.css`, `data.js` (all map data), `app.js` (code) |
| `airport/` | Interactive airport map of Silverbrooks Thompson International (SBX/KSBX) |
| `transit/` | SBTrain, SBMetro, ALBExpress and SBFerry maps, plus livery images |
| `media/` | The Silverbrooks Times, University News, reels |
| `app/`, `sw.js`, `manifest.json` | Web app shell: Home button on every page, offline cache, install info |
| `brand/ads/` | Logos and ad art used on the liveries |

Canon lives in the World Bible doc on claude.ai. This repo is the backup and the public site.

**Install as an app:** open the live site on your phone, then Share > Add to Home Screen (iPhone) or menu > Install app (Android). Every page has a Home button back to the launcher.
